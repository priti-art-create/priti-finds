# ✨ Priti Finds

Priti Finds is a beginner-friendly fashion and lifestyle website created using HTML, CSS, and JavaScript.

The website provides fashion inspiration, college essentials, accessories, and gift ideas in a simple and attractive design.

## 🌸 Features

- 👗 Fashion and outfit inspiration
- 👜 College bags and accessories
- 💎 Jewellery ideas
- 👟 Shoes and styling ideas
- 📚 College and study essentials
- 🎁 Gift ideas
- 🌙 Dark Mode
- 🔍 Search functionality
- ⌨️ Search using the Enter key
- ❤️ Favorite buttons
- 💾 Favorites saved using localStorage
- 📱 Responsive design for smaller screens

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser localStorage
